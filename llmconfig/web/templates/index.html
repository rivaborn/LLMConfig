Every LLM unit at a glance. Pick a model to load it on that unit — a GPU lane swaps to it (one model per card), a Spark adds it alongside whatever is already resident.

Cookbook

Pick Spark nodes, then a model that fits that many. One node uses the normal single-node load; two or more launch a single tensor-parallel job spanning them (each node claimed whole). Multi-node models live in the cluster catalog only.

Recorded placements

Every (model, node set) that has launched successfully — these survive restarts and are what auto-placement may cold-start.
